    Python Module Directory: Logic & Code Snippets

    This comprehensive directory provides a file-by-file breakdown of the GTM Validator codebase. It explains the core logic of every important module and includes actual code snippets to illustrate the implementation.

    📂 gtm/ (Core Assessment Engine)

    The gtm app is the heart of the platform, managing the diagnostic framework, scoring math, and AI strategy generation.

    📄 gtm/models.py

    Responsibility: Defines the relational schema for the assessment framework. - Category & Question: The building blocks of the diagnostic. - AssessmentSession: Tracks a single user's journey. - ResultSnapshot: A denormalized record that "freezes" the company's state and stores the final AI playbook. - GTMFile: Multimodal "Strategic Evidence" with AI audit fields.

    📄 gtm/views.py

    Responsibility: Manages the high-interactivity assessment wizard using HTMX. - Logic Snippet: Partial Rendering 

    def _get_template(request, base_template, partial_template=None):
    # Detect HTMX request to return only the form segment
    if request.headers.get('HX-Request') == 'true' and partial_template:
        return partial_template
    return base_template
