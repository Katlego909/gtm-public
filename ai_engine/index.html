    Intelligence & AI Engine: Technical Reference

    The Big Picture

    The AI Engine is the GTM Validator's "Executive Consultant." It doesn't just generate text; it observes the database state, audits visual files, and mutates the task backlog. The architecture is built for resilience, ensuring that even if Gemini is down, the user still receives high-quality pre-written guidance.

    1. Interaction Layer (gtm/ai_services.py)

    The system interacts with Vertex AI via the google-genai SDK. The core entry point is generate_playbook_with_gemini.

    Prompt Orchestration

    Prompts are not static strings; they are dynamically constructed using data from the ResultSnapshot.

    # gtm/ai_services.py
def _build_playbook_prompt(snapshot):
    category_data = snapshot.category_breakdown
    weak_answers = Response.objects.filter(session=snapshot.session, score__lte=2)

    # The prompt forces a specific JSON structure for easy parsing
    return f"""
    Analyze this GTM data for {snapshot.company_name} ({snapshot.industry}):
    Overall Score: {snapshot.overall}
    Categories: {json.dumps(category_data)}
    Weak Points: {[r.question.text for r in weak_answers]}

    Return a JSON object with: 
    - "markdown_playbook": A 30-day strategy.
    - "financial_summary": Estimated ROI.
    - "competitor_analysis": Gap assessment.
    """

    2. Multimodal Auditor (gtm/ai_auditor.py)

    The auditor handles visual strategic evidence. It supports Image (Landing Pages) and PDF (Sales Decks).

    Binary Data Flow

    Files are never sent as URLs; they are sent as raw binary parts to ensure the AI "sees" the exact state of the asset.

    # gtm/ai_auditor.py
def audit_gtm_file(gtm_file_id):
    file_obj = GTMFile.objects.get(id=gtm_file_id)
    with file_obj.file.open('rb') as f:
        content = f.read()

    # Multimodal call sending text prompt + image bytes
    response = client.models.generate_content(
        model='gemini-2.5-flash',
        contents=[
            types.Part.from_text("Critique this landing page for GTM clarity."),
            types.Part.from_bytes(data=content, mime_type="image/png")
        ]
    )
