    Hosting & Deploying the Documentation

    The GTM Validator documentation is built using MkDocs and the Material for MkDocs theme. It is a static site, meaning it can be hosted almost anywhere for free or at a very low cost.

    1. Local Hosting (For Development)

    If you just want to view the documentation on your own machine while making changes:

    1. Activate your virtual environment: 
      venv\Scripts\activate
    2. Run the built-in development server: 
      python -m mkdocs serve
    3. Open your browser to http://127.0.0.1:8000. The page will automatically refresh as you save changes to your Markdown files.

    2. Generating the Static Site

    To prepare the documentation for deployment, you must "build" it into a set of HTML files:

    python -m mkdocs build

    This will create a folder named site/ in your project root. This folder contains everything needed to host the documentation.

    3. Deployment Options

    A. GitHub Pages (Recommended)

    If your code is on GitHub, this is the easiest option. MkDocs has a built-in command for this:

    python -m mkdocs gh-deploy

    This command will: 1. Build your documentation. 2. Create a gh-pages branch in your repository. 3. Push the HTML files to that branch. 4. GitHub will then host it automatically at https://<your-username>.github.io/gtm-public/.

    B. Netlify or Vercel

    These platforms are excellent for static sites: 1. Connect your GitHub/GitLab repository to Netlify/Vercel. 2. Set the Build Command to: python -m mkdocs build 3. Set the Publish Directory to: site/ 4. Every time you push to your master branch, your documentation site will update automatically.

    C. Hosting with the Main Application

    If you want the documentation to be accessible at your-app.com/docs/: 1. Build the site: python -m mkdocs build. 2. Move the site/ folder into your Django project's static/ directory or configure your web server (Nginx/Apache) to serve the site/ folder at the /docs/ path. 3. Note: Using a dedicated static host (like GitHub Pages) is usually better for performance and security.

    🛠️ Troubleshooting

    • Missing Dependencies: If the build fails, ensure you have the required packages: 
      pip install mkdocs-material pymdown-extensions
    • Broken Links: MkDocs will warn you during the build process if any internal links are broken.
